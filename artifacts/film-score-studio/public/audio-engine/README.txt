SpessaSynth AudioWorklet static asset
=====================================

The production file spessasynth_processor-4.3.14.min.js is emitted from the
pinned spessasynth_lib 4.3.14 package by vite.config.ts. Development serves
the identical untransformed upstream bytes at this path.

When updating spessasynth_lib, update the versioned filename and source
reference in vite.config.ts and src/lib/spessasynth-worklet.ts together.
The upstream Apache-2.0 license is retained at:
../soundfonts/licenses/spessasynth-lib.apache-2.0.txt
