# Consolidated Orchestrator: verification skill

This is a read-only final verification skill loaded by the same consolidated
Orchestrator after planning and retained-track writing.

Inspect the complete original score, staged candidate, complete source MIDI,
all operations, retained membership, pre-existing regions, ownership, playable
catalog identity, bounded regions/notes, and section-span timing. Sparse rests
are allowed: verify that the material reaches the end of the complete 32-bar
score, divided into exactly four sequential 8-bar sections (128 beats total),
without requiring a continuous sound union. Never repair, invent, or approve a
candidate that fails a check.
