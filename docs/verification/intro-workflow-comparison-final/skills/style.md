# Consolidated Orchestrator: style skill

This is a read-only, on-demand style skill loaded by the experiment's single
Orchestrator. It does not own score operations, track membership, or approval.

Return concise, actionable guidance for an original-neutral cinematic intro:
palette, dynamics, texture, register, pacing, and playable orchestration. Use
only the retained playable catalog. Optional MIDI is private advisory evidence
and must never be treated as a score edit. Preserve the full supplied score and
source MIDI context. Prefer sparse phrases with rests and multiple bounded
regions rather than filling every beat.
